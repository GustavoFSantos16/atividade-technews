# 📱 TechNews Today - Portal de Tecnologia

O **TechNews Today** é um portal moderno de notícias de tecnologia projetado com foco em experiência visual imersiva, alta legibilidade e design responsivo. O layout utiliza tendências contemporâneas de design de interface, como o glassmorphism e gradientes vibrantes para criar uma atmosfera futurista e tecnológica.

## 🚀 Funcionalidades e Estrutura

**Cabeçalho com Efeito Glassmorphism:** Barra superior fixa com desfoque de fundo e gradiente sutil.
**Layout com CSS Grid:** Estrutura flexível que organiza o conteúdo de forma inteligente.
**Artigo em Card Moderno:** Destaque de notícias com transições suaves e interações ao passar o mouse (hover).
**Seção de Vídeo Integrada:** Incorporação de reprodutor de vídeo com moldura estilizada.
**Formulário de Newsletter:** Seção de captura de e-mails com seleção de interesses (IA, Mobile, Web) e design estilizado.
**Responsividade Completa:** Adaptação automática do layout para dispositivos móveis e desktops via Media Queries.

## 🎨 Características de Design (CSS)

**Paleta de Cores:** Fundo ultra-escuro (#0a0e27) com contrastes em azul neon (#60a5fa), roxo (#8b5cf6), rosa (#db2777) e detalhes em laranja/âmbar (#f59e0b).
**Tipografia:** Sistema de fontes nativas modernas (-apple-system, BlinkMacSystemFont, Segoe UI).
**Efeitos Visuais:** Uso de backdrop-filter: blur(10px) para o menu e transform: translateY para animações em cards.

## 🛠️ Tecnologias Utilizadas

**HTML5:** Estruturação semântica (uso de header, article, section, summary, footer).
**CSS3:** Estilização avançada, Grid Layout, Flexbox, Pseudo-classes e Responsividade.

## 💻 Como Executar o Projeto

1. Clone ou baixe os arquivos deste repositório.
2. Certifique-se de que os arquivos index.html e style.css estejam no mesmo diretório (ou ajuste o caminho da tag <link> no HTML).
3. Abra o arquivo index.html diretamente em qualquer navegador web de sua preferência.
